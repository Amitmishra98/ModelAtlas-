## 1. Rename the repository (recommended, optional)

Settings → General → **Repository name**

| Field | Value |
|---|---|
| Repository name | `modelatlas` |

- GitHub automatically redirects the old URL (`/Amitmishra98/.p`) to the new
  one, so existing links and clones keep working.
- A clean, descriptive name helps search engines and AI assistants identify
